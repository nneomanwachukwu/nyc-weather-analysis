# 31-day NYC Weather Analysis

This project analyzes 31 days of New York City weather data using Python and Pandas. The objective is to explore weather patterns, perform data cleaning, analyse temperature and precipitation trends, and present insights through data visualisation

## Tools Used

- python
- pandas
- Jupyter Notebook

## Skills Demonstrated

- Data Cleaning
- Data Analysis
- Data Visualization
- File Handling
- Exploratory Data Analysis (EDA)

## Project Objective

The objective of this project is to analyze 31 days of New York City weather data to identify trends in temperature and precipitation, practice data analysis techniques using Python and Pandas, and communicate findings through clear visualisations and analyses.

## Dataset

- **Dataset:** NYC Weather Dataset
- **Duration:** 31 Days
- **Format:** CSV
